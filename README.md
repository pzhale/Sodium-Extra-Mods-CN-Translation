# 开发背景
虽然Sodium已经有了[非官方汉化包](https://modrinth.com/resourcepack/translations-for-sodium)，但却没多少人做它的附属模组的汉化 (要不就是下载量很少)
这对我来说无疑是难受的，于是这个汉化资源包就这么开发出来了

Although Sodium already has an [unofficial Chinese translation pack](https://modrinth.com/resourcepack/translations-for-sodium), not many people have translated its add-on mods (or the download numbers are really low).
This is definitely frustrating for me, so this translation resource pack was developed.

### 该资源包为Sodium的部分附属模组提供中文翻译

目前支持:
- [Reese's Sodium Options](https://modrinth.com/mod/reeses-sodium-options)
- [Sodium Extra](https://modrinth.com/mod/sodium-extra)
- Sodium Leaf Culling [官方版 (Official)](https://modrinth.com/mod/sodiumleafculling) / [非官方版 (Unofficial)](https://modrinth.com/mod/sodiumleafculling-unofficial)
- [Sodium Low Fire Shield](https://modrinth.com/mod/sodium-low-fire-shield) (v0.1.2 above)
- [Nvidium](https://modrinth.com/mod/nvidium/) or [Acedium Sodiumized](https://modrinth.com/mod/acedium-sodiumized) (v0.1.2 above)

后续更多附属模组汉化支持敬请期待！
如有翻译错误, 请提交issue

Stay tuned for more translation support for additional modules coming soon!
If there's a translation mistake, please submit an issue.
